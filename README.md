<!-- CLASS RECORD MANAGER -->


<!-- What Does The Program Do? -->
The program is a simple classroom record manager. It helps in keeping record of what goes on in a class. It keeps record like; student id, name, course, score, class statistics. The program has features that enables users to add students, update students' scores, search for students and even delete students. 

<!-- How To Run It -->
When running the program, you have different options to access each of the features mentioned in the above paragraph.

<!-- Data Structures I Used -->
I used lists and dictionaries. Precisely I used a list of dictionaries.

<!-- Why I Choosed The Data Structures -->
I choosed the above data structures because I'm storing values that involves key and values. The list then nests each of those values. Thus, a list of dictionaries.

<!-- How The Data is Saved -->
The data is first saved automatically to the students.json file and is later saved to the students.csv file if the user inputs the option to export records to csv.
